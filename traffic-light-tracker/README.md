# 🚦 Red Light Tracker

A single-file web app for logging drivers who run red lights.

## Use it

Open `index.html` in any browser. You don't need to install anything or run a server.

## Features

- Log an offence with plate number, location, date and time, fine and notes
- Flags repeat offenders automatically
- Shows totals: offences, unique vehicles, repeat offenders, total fines and the plate with the most offences
- Search by plate or location
- Export the log to CSV
- Saves data in the browser's `localStorage`, so it stays on this device only
